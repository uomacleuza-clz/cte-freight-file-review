# Cte Freight File Review

Crie uma aplicação web chamada Controle de Fretes — Importação CT-e.

A aplicação será utilizada internamente por usuários autorizados de uma empresa, acessada pelo navegador, sem instalação nos computadores.

Crie inicialmente uma página chamada Importação CONEMB 5.0, contendo:

Cabeçalho com o título "Controle de Fretes — Importação CT-e".

Área para selecionar vários arquivos TXT simultaneamente.

Tabela com nome do arquivo, tamanho, data da seleção e situação.

Botão "Validar Arquivos".

Área de pré-visualização dos CT-es encontrados nos arquivos.

Botão "Processar Arquivos", inicialmente desabilitado.

Área de mensagens de erros e avisos.

Menu lateral com "Importação CT-e", "Consulta CT-e" e "Histórico de Importações".

Utilize um visual profissional, com fundo claro, tabelas organizadas e botões bem identificados.

Nesta primeira etapa, crie somente a interface visual. Não implemente ainda a leitura do layout CONEMB 5.0, o banco de dados nem o processamento real dos arquivos.

Não utilize dados fictícios como se fossem importações reais.
